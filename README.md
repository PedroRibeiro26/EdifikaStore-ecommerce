# EdifikaStore
Projeto de um site e-commerce sobre Material de construção

---

## 📌 Escopo do Projeto  

### ✨ Funcionalidades Principais  
- **Catálogo de Produtos** → Exibição dos produtos com imagens, descrições e categorias.  
- **Busca de Produtos** → Barra de pesquisa para encontrar um produto desejado pelo nome.  
- **Carrinho de Compras** → Adicionar produtos ao carrinho e visualizar o total da compra.  
- **Pagamento via QR Code** → Geração de QR Code com os dados da transação.  
- **Integração com APIs** →    
  - [DummyJSON](https://dummyjson.com) para buscar dados fictícios (mock) para testes.
  - API de QR Code para gerar o código de pagamento.  

---

## 🛠️ Tecnologias Utilizadas  

### Frontend  
- **HTML5**, **CSS3**, **Bootstrap**, **JavaScript**

### Backend / Integrações  
- **DummyJSON API** → informações sobre jogos  
- **QR Code API** → geração do código de pagamento  

### Outras ferramentas  
- **GitHub** → controle de versão e hospedagem do repositório  

---

## 🎯 Objetivos  
- Criar um site funcional que permita **buscar, filtrar, comprar e pagar por produtos online**.  
- Utilizar **APIs externas** para enriquecer a experiência do usuário.  
- Aplicar **boas práticas de desenvolvimento** (uso de Git/GitHub, organização de código, versionamento).  

---

## 💡 Motivo do Projeto  
O projeto nasceu da pura necessidade de prática e do interesse em **explorar conceitos de comércio digital**, unindo diversão e aprendizado em uma aplicação.
